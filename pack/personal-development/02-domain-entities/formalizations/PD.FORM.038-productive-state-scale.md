# Формализация: Шкала продуктивного состояния (Productive State Scale)

## 1. Определение

Формальная 6-уровневая шкала продуктивного состояния, где каждый уровень имеет название, описание и предписанный класс активности.

## 2. Шкала

| Уровень | Название | Описание | Предписанная активность |
|---------|----------|----------|------------------------|
| 0 | Critical (Критический) | Блэкаут, невозможность функционировать | Только сон и базовый уход; при остром или устойчивом неблагополучии — профильная помощь |
| 1 | Failure (Провал) | Невозможность сфокусироваться | Пассивный отдых |
| 2 | Decline (Спад) | Сигнал тревоги | Только активный досуг |
| 3 | Satisfactory (Удовлетворительный) | На пределе | Простые задачи |
| 4 | Functional (Рабочий) | Стабильный рабочий режим | Рутинные задачи |
| 5 | Peak (Пиковый) | Способность к потоку | Глубокая работа |

## 3. Спектр состояний

Шкала описывает **непрерывный спектр**, а не дискретные ступени. Человек находится в каком-то месте спектра в каждый момент времени и перемещается по нему в течение дня.

```
Критическое (0) ← Провал (1) ← Спад (2) ← Удовлетворительное (3) ← Рабочее (4) ← Пиковое (5)
```

**Потоковое состояние (flow)** — пиковая точка спектра. Возникает при совпадении: высокий навык + высокий вызов + ясная цель + немедленная обратная связь (Csikszentmihalyi, 1990). На ступенях ученика 1-2 потоковые состояния редки — это нормально, недостаточно навыков для баланса навык/вызов.

**Движение по спектру — не случайность.** Состояние можно целенаправленно смещать вверх через три механизма: восстановление (сон, отдых), активацию (движение, свет, холод), погружение (устранение отвлечений, ритуализация начала работы).

## 4. Досуг как управление состоянием

Досуг — не «отсутствие работы», а **инструмент возврата в продуктивную зону спектра** (PD.METHOD.006). Три масштаба досуга действуют на разные зоны спектра:

| Масштаб досуга | Что делает со спектром | Пример |
|----------------|------------------------|--------|
| **Микро** (5-15 мин) | На уровне 2 — короткий активный досуг; уровни 0–1 требуют базового ухода или пассивного отдыха, а не активации | Короткая прогулка, дыхание, разминка |
| **Мезо** (1-4 часа) | На уровне 2 — восстановление к удовлетворительному или рабочему состоянию (3–4); применяется только после выхода из уровней 0–1 | Спорт, творческое хобби, прогулка в природе |
| **Макро** (день+) | Восстановление ресурсной базы; пиковое состояние может появиться позже, но не гарантируется самим досугом | Путешествие, ретрит, длительный проект-хобби |

**Скука как сигнал:** отсутствие новых впечатлений → «конвейер впечатлений» (PD.METHOD.006) пуст → нет сырья для роста мировоззрения → стагнация на текущей ступени. Скука на ступенях ученика 3-4 — индикатор необходимости расширять окружение (PD.METHOD.006).

## 4.1 Правило золотого часа: планирование под состояние

> Планирование времени без учёта продуктивного состояния ведёт к выгоранию. Шкала даёт основу для другого способа планирования — под **состояние, а не под часы**.

**Недельный лимит (операционное правило):**
- **2-4 часа «высокой сложности» в день** — под важные рабочие продукты в фактически достигнутом состоянии 5
- **4-6 часов «рабочего фона»** — под текущие и рутинные задачи в состояниях 3–4 с подбором сложности по строкам шкалы
- Нельзя ставить подряд недели с максимальной когнитивной нагрузкой — запланированная передышка требуется каждые 2-3 недели

**Недельная сессия планирования:**
1. Формирование списка рабочих продуктов
2. Каждому РП: метка **«важное» vs «текущее»** + оценка трудности и времени
3. Проверка лимита: сколько «важного» поместится в неделю (не более N×(2-4) часов при N рабочих дней)
4. Сцепление недельных РП с целями месяца и года

**Дневной протокол:**

| Состояние | Что делать |
|-----------|-----------|
| **5 — Peak (Пиковый)** | Глубокая работа над главным продуктом дня; ясная цель и обратная связь обязательны |
| **4 — Functional (Рабочий)** | Рутинные задачи в устойчивом рабочем режиме; сложную работу переносить в состояние 5 |
| **3 — Satisfactory (Удовлетворительный)** | Только простые задачи с низкой ценой ошибки; при снижении состояния прекращать работу |
| **2 — Decline (Спад)** | Только активный досуг: прогулка, лёгкое движение, смена обстановки; рабочие задачи не ставить |
| **1 — Failure (Провал)** | Пассивный отдых, отключение от задач и восстановление |
| **0 — Critical (Критический)** | Сон и базовый уход; при остром или устойчивом неблагополучии — обращение за профильной помощью |

**Ритуалы входа/выхода:** перед стартом сложной работы — сформулировать одной фразой «что должно быть готово через час-два», включить таймер, определить роль и метод, убрать помехи.

**Зрелость практики:** по журналу трекинга времени доля «важного» растёт от случайных эпизодов (ст. 1) до трети-половины общего времени (ст. 4-5). Это косвенный индикатор зрелости по M1 (собранность).

## 5. Связь со ступенями ученика (PD.FORM.003)

| Ступень | Типичная зона спектра | Причина | Задача программы |
|---------|----------------------|---------|------------------|
| Случайный (1) | Хаотично: 0-3, без управления | Нет осознания состояний | Ввести мониторинг состояний |
| Практикующий (2) | 2-4, первые попытки управления | Начал замечать связь состояние→результат | Научить восстановлению (микродосуг) |
| Систематический (3) | 3-5, стабильный ритм | Ритм и методы встроены | Целенаправленное управление (мезодосуг) |
| Дисциплинированный (4) | 4-5, устойчивый | Состояния не требуют усилий | Потоковые состояния в работе и окружении |
| Проактивный (5) | 4-5, осознанный | Управление состояниями = привычка | Состояние как ресурс для созидания |

## 6. Применение

- **Самомониторинг**: оценка текущего уровня перед выбором задачи
- **Task-state matching**: глубокие задачи только на уровне 5, рутинные на 4, простые на 3, восстановление на 0–2
- **Trend tracking**: отслеживание динамики по дням/неделям
- **Досуг-дизайн**: выбор масштаба досуга исходя из текущей зоны спектра
